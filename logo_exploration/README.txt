# Engineering Lab — Logo Exploration

This package contains three original SVG redraws based on the three reference images supplied by the user.

For each concept:
- `*-emblem-light.svg`: standalone emblem for light surfaces
- `*-emblem-dark.svg`: standalone emblem for dark surfaces
- `*-logo-light.svg`: horizontal full logo for light surfaces
- `*-logo-dark.svg`: horizontal full logo for dark surfaces

Palette:
- Light accent: #2563EB
- Dark accent: #60A5FA
- Light wordmark: #0F172A
- Dark wordmark: #E8EEF5

All SVGs have transparent backgrounds. These are first-pass vector redraws for visual review; they are not claimed to be pixel-identical traces of the JPEGs. The supplied references are raster images, so exact node placement and line contours may need a refinement pass after the user chooses preferred details.

No GitHub repository files were changed and no commits were made.
